# apps/web

Frontend Next.js 15 (App Router, TypeScript estricto, Tailwind, shadcn/ui) de la aplicación de
gestión de activos de TI. Ver la documentación del monorepo en [`../../docs`](../../docs) y las
convenciones en [`../../CLAUDE.md`](../../CLAUDE.md).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
npx tsc --noEmit
```

Variables de entorno: ver [`.env.example`](.env.example).
